# Tara 項目跟蹤

一個簡潔的網頁版日程與專案管理工具，使用純 HTML + CSS + JavaScript 製作，資料存在瀏覽器本地（localStorage）。

## 功能

- *月曆檢視* 與 *本週檢視*
- 按專案以不同顏色標記任務
- 點擊某一天查看當日任務總覽與順序
- 每個專案有獨立的時間線視圖
- 任務可勾選完成、編輯、刪除
- 支援在不同日期之間拖動任務
- 標題「Tara」可自訂並自動保存

## 使用方式

1. 直接用瀏覽器打開 project-manager.html 即可使用。
2. 所有資料都存在你目前使用的瀏覽器中，不需要伺服器。
3. 如需在電腦與手機之間同步，請使用瀏覽器的「匯出／匯入」功能（或將檔案部署到 GitHub Pages 後使用同一網址）。

## 部署到 GitHub Pages

1. 將本倉庫設為 Public。
2. 進入 *Settings → Pages*。
3. Source 選擇 *Deploy from a branch*，Branch 選擇 main，資料夾選擇 / (root)。
